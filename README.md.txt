
# Startup Funding Analysis Using SQL

## Project Overview

This project explores a simulated startup funding dataset using SQL in MySQL Workbench. The analysis investigates startup funding patterns across industries, countries, funding stages, and investors.

The goal is to practice SQL data exploration, aggregation, filtering, sorting, and joining tables to answer business questions and communicate useful findings.

## Tools Used

- MySQL
- MySQL Workbench
- SQL

## Dataset

The dataset contains four tables:

- `startups`
- `funding_rounds`
- `investors`
- `round_investors`

**Note:** This is a simulated dataset created for learning and portfolio practice. The findings should not be interpreted as real-world investment statistics.

## Analysis Performed

- Explored tables and records.
- Filtered startups by country and funding rounds by amount.
- Calculated total and average funding.
- Compared funding across industries, countries, and funding stages.
- Counted funding rounds per startup.
- Identified investors with the most recorded participations.
- Examined lead-investor activity.
- Joined tables to combine startup, funding, and investor information.
- Checked for duplicate IDs and missing values in selected fields.
- Used Common Table Expressions (CTEs) to organize funding analysis.

## Key Findings

Results and interpretations will be documented after reviewing the SQL query outputs.

## Limitations

The dataset is simulated and limited in size. The findings demonstrate SQL analysis techniques rather than actual market trends.
